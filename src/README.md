# TheNaxalArchive website

## Main navigation
- Home
- Background (History / Ideology)
- Data & Visuals (Map / People / Infrastructure)
- News Desk
- Opinions
- Tracking Development (Development / Reports)

## Deploy
Replace your repository `index.html` with this version and commit to `main`.

The interactive map in the current HTML expects these files beside `index.html`:
- `lwe-data.js`
- `lwe-affected-districts.csv`

Copy the verified versions of those files into the repository root. No placeholder data is included here.
